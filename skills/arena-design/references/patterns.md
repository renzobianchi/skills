# Local pattern catalog (fallback without Mobbin)

Minimal vocabulary of production patterns by problem type, for building the grounding memo when neither Mobbin nor search is available. Name the pattern by name in the memo; split candidate directions by picking patterns from different families.

## Navigation
- **Tab bar / bottom nav** (mobile, 3-5 flat destinations) · **collapsible sidebar** (dense desktop) · **top nav + mega-menu** (marketing) · **command palette (⌘K)** (power users) · **drawer** (secondary, never primary) · **breadcrumbs** (deep hierarchies).

## Dense lists and tables
- **Table with expandable rows** (detail without leaving) · **master-detail / split view** (comparing records) · **card grid** (visual content, few dimensions) · **list with filter bar + chips** (active facets visible, `+N` overflow) · **saved / named views** (recurring queries) · **virtualization + pagination** (thousands of rows) · **row hover actions vs a fixed actions column**.

## Forms and input
- **Single column, labels on top** (default) · **wizard / stepper** (long tasks with state) · **inline editing** (spot corrections in tables) · **modal form** (short creation in context) · **dedicated page** (long creation or with preview) · **on-blur validation + error summary on submit**.

## Dashboards and dataviz
- **KPI row + main chart + detail table** (the classic hierarchy) · **reorderable module grid** (personalization) · **overview → click-through drill-down** · **sparklines in rows** (trend without footprint) · **global date/segment filters on top, persistent**.

## Empty states and onboarding
- **Empty state with a primary action** (first use) ≠ **no results with a filter reset** ≠ **error with retry** — always distinguish them · **setup checklist** (multi-step activation) · **togglable demo data** (try before connecting) · **contextual tooltip tour** (beats a welcome modal).

## Object detail
- **Header with identity + actions, section tabs** (rich objects) · **sliding side panel** (detail without losing the list) · **activity timeline** (history) · **copyable fields with an affordance** (technical IDs).

## Selection and settings
- **Settings grouped by domain, with search** · **toggles labeled for their ON state** · **radio cards** (few comparable options, price/consequence visible) · **progressive disclosure of advanced options** (with a visible affordance).

## Marketing and landing
- **Statement-first hero + single CTA** · **social proof as a logo cloud with provenance** · **features as media/text zig-zag** vs **card grid** (comparability is the decision) · **pricing columns with the recommended one highlighted** · **footer as sitemap**.
